Política de privacidad

Última actualización: 18 de noviembre de 2026.

La aplicación "Marketing Glossary" es una herramienta interna que usa el propietario del canal de YouTube MarketingGlossary para subir y administrar los videos de su propio canal mediante la API de datos de YouTube.

Datos a los que accede

Solo accede a la cuenta de YouTube del propio canal, con el permiso que su propietario otorga en la pantalla de consentimiento de Google: subir videos, editar sus datos (título, descripción, miniatura, estado de publicación) y leer estadísticas y comentarios del canal.

Uso y almacenamiento

El token de acceso se guarda únicamente en el equipo del propietario. La aplicación no recopila, vende ni comparte datos de otras personas, y no usa los datos para publicidad.

El uso de la información recibida de las API de Google cumple con la Política de datos del usuario de los servicios de las API de Google, incluidos los requisitos de uso limitado. Al usar la aplicación también se aplican las Condiciones del servicio de YouTube y la Política de privacidad de Google.

Revocar el acceso

El acceso se puede revocar en cualquier momento desde la configuración de seguridad de la cuenta de Google.
